## Endpoint

```http
GET /api/v1/payments
```

**Authentification :** Header `X-API-Key`

## Paramètres de requête (query string)

| Paramètre | Type | Défaut | Description |
|-----------|------|--------|-------------|
| `status` | string | — | Filtrer par statut (`pending`, `paid`, `cancelled`) |
| `limit` | number | 50 | Nombre de résultats (max 100) |
| `offset` | number | 0 | Décalage pour la pagination |

## Exemple de requête

<Tabs>
  <TabItem label="cURL">
  ```bash
  # Toutes les transactions payées, page 1
  curl "https://api.lawpay.sn/api/v1/payments?status=paid&limit=20&offset=0" \
    -H "X-API-Key: lp_live_xxxxxxxxxxxxxxxxxxxx"
  ```
  </TabItem>
  <TabItem label="JavaScript">
  ```javascript
  const params = new URLSearchParams({
    status: 'paid',
    limit: '20',
    offset: '0',
  });

  const response = await fetch(
    `https://api.lawpay.sn/api/v1/payments?${params}`,
    {
      headers: { 'X-API-Key': process.env.LAWPAY_API_KEY },
    }
  );

  const { data } = await response.json();
  console.log(`${data.total} transactions au total`);
  console.log(data.transactions); // Array de transactions
  ```
  </TabItem>
</Tabs>

## Pagination

Utilisez `offset` et `limit` pour paginer les résultats :

```javascript
// Page 1
const page1 = await fetchPayments({ limit: 20, offset: 0 });

// Page 2
const page2 = await fetchPayments({ limit: 20, offset: 20 });

// Nombre total de pages
const totalPages = Math.ceil(page1.data.total / 20);
```
