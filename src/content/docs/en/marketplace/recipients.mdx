A recipient is a business on your marketplace, identified by the mobile money
number LawPay pays routed payments to.

**Authentication:** `X-API-Key` header. The project must be in
[marketplace mode](/en/marketplace/overview/).

## Create a recipient

```http
POST /api/v1/recipients
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `name` | string | ✅ | Business name |
| `destinationNumber` | string | ✅ | Mobile money number that receives payouts |
| `service` | string | ✅ | Operator: `"Orange Money Senegal"`, `"Wave Senegal"`, `"Free Money Senegal"`, `"Expresso Senegal"` |
| `externalId` | string | — | Your own id for the business, unique per project. Lets you route a payment with `recipientExternalId` without storing the LawPay id |
| `email` | string | — | Business contact |
| `phone` | string | — | Business contact |
| `metadata` | object | — | Free-form data |

## List recipients

```http
GET /api/v1/recipients?status=active&limit=50&offset=0
```

Returns `{ recipients, total, limit, offset }`.

## Get a recipient

```http
GET /api/v1/recipients/:id
```

Includes a `stats` object: `paid_count`, `total_paid_out`, `failed_payouts`.

## Update a recipient

```http
PATCH /api/v1/recipients/:id
```

All fields optional: `name`, `destinationNumber`, `service`, `email`, `phone`,
`status` (`active` | `suspended`), `metadata`.

<Aside type="caution">
  Changing `destinationNumber` or `service` redirects the business's money. It
  is written to the project's audit log and emits a `recipient.updated` webhook
  with `destinationChanged: true`. Watch for that event.
</Aside>

## Suspend a recipient

```http
DELETE /api/v1/recipients/:id
```

The recipient becomes `suspended`: existing payments remain visible, but no new
payment can be routed to them (`RECIPIENT_SUSPENDED`) and failed payouts are no
longer retried. Reactivate with `PATCH { "status": "active" }`.

## Errors

| HTTP | Code | When |
|------|------|------|
| 400 | `MARKETPLACE_DISABLED` | The project is not in marketplace mode |
| 400 | `VALIDATION` | Missing required field or invalid `status` |
| 404 | `NOT_FOUND` | Unknown recipient for this project |
| 409 | `CONFLICT` | `externalId` already used in this project |
